Carpet comes off the roll in lengths called drops, and the pile has to run the same way in all of them — so a drop cannot be turned round to save material. Turning the drops can change how many you need.

Stairs mm

Leave everything at 0 if there are no stairs. A flight is not part of any floor's footprint, so it is described here rather than drawn. A winder is a turning tread taking a corner instead of a landing; each one is cut from a square of the stair width, because the offcut off a triangular tread will not fit the next.
